# 全知库 · AllKnow

> 最后更新：2026-09-10

一个聚焦组织内部流程的本地知识管理平台。它以“内部知识库”为唯一知识领域，以机房运维为流程入口，让运维文档可按分类浏览，也能通过双向连接形成完整图谱。

## 当前功能

- 知识领域只保留“内部知识库”，在左侧“知识领域”栏中展示为层级目录
- 内部知识库下设机房运维入口，机房运维内包含交付相关文档库与设施相关文档库
- “文档库”页面顶部固定展示交付、设施两个二级文档库，可直接进入分类
- 4 条内置演示知识，覆盖内部知识全景、机房运维、交付相关知识与设施相关知识
- Markdown 编辑与预览，`[[条目名]]` 自动生成双向连接
- 工作台、领域树、全部条目、知识图谱四类视图
- 标题、正文、标签、状态、置信度、来源与收藏的自动保存
- 条目附件支持上传文档、表格、图片、音频与视频；视频可直接播放，PDF、Word（DOCX）、Excel/CSV、TXT、Markdown 和 JSON 可内嵌预览，并支持下载和删除
- 上传 TXT/Markdown/CSV/DOCX/XLSX/PDF 后调用本机 Codex 真实模型，自动整理长文、乱格式、重复内容和断裂段落，先按业务流程分类分段，再按步骤编号顺序提取步骤名、操作内容和独立要点；备注、注意或风险信息只用于补全步骤正文，最终不显示“备注”标签或独立备注区，未启动本地 AI 服务时降级为本地结构化提取
- 音频与视频附件可通过语音转写识别内容，图片附件可通过视觉模型 OCR 提取文字；语音转写与视觉识别可在“数据与设置”中配置云端接口
- 全文搜索与按领域/状态/标签筛选
- 图谱可缩放、平移、按领域聚焦
- JSON 导入导出，文档与媒体文件通过浏览器 IndexedDB 本地保存
- AI 助手（问知识库）会自动检索内部资料并引用来源回答；附件上传后自动用真实 AI 整理正文，无需配置 API Key；语音转写、图片识别与备用云端接口可在“数据与设置”中配置
- 本机 AI 服务自动读取 Codex 配置与 `auth.json` 鉴权；本地代理令牌无效时自动切换到真实可用的 DeepSeek 快速直连，并关闭推理过程、启用 JSON 结构化输出，文档提取通常在约 1–3 秒完成，模型切换后无需手动重启服务
- “数据与设置 → AI 智能读取”展示本机 AI 连接状态、模型名称和已启用能力，并提供“重新检测”按钮

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 技术结构

- React 19 + Vite 6 + TypeScript
- `lucide-react` 图标
- `marked` + `dompurify` Markdown 渲染
- `mammoth`、`xlsx`、`pdfjs-dist` 附件文字提取
- 浏览器本地存储，无后端依赖

核心文件：

- `src/data/domains.ts`：领域与分支定义
- `src/data/seed.ts`：演示知识库种子数据
- `src/lib/aiExtract.ts`：附件文字提取与 AI 结构化
- `src/lib/mediaAi.ts`：音频/视频语音转写与图片 OCR 识别
- `src/components/AiAssistant.tsx`：AI 智能问答界面
- `src/lib/notes.ts`：双向链接、搜索与时间工具
- `src/App.tsx`：路由与数据状态
- `src/components/`：工作台、列表、领域树、图谱、编辑器等页面

## 扩展路线

- 将 `localStorage` 替换为 Supabase / Postgres / SQLite API，支持多端同步与协作
- 增加全文检索引擎与向量检索，为后续“问知识库”提供入口
- 支持附件、图片、引用文献与 PDF 摘要
- 把真实制度、SOP、验收表和机房运维台账持续沉淀进机房运维分类

运维知识依赖持续积累与可靠连接；这个平台把内部知识库的骨架先立起来，机房运维下的条目可以不断扩展。
